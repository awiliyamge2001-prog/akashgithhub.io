Production Security Architecture

  • Stateless JWT Verification: HMAC-SHA256 signature verification performed at the Gateway ingress filter before forwarding requests to internal services.
  • Distributed Rate Limiting: Configured at 100 requests per minute per IP token bucket to defend services against DoS abuse.
  • Internal X-API-KEY Filter: Microservices verify internal gateway tokens to prevent direct bypass access.

Container Orchestration & QA

  • Docker Compose Cluster: 8-service local cluster orchestration (`docker compose up --build -d`) with isolated bridge network, health checks, and volume mapping.
  • Automated Postman Test Suites: Pre-configured collections with assertion scripts covering auth handshakes, ticketing checkout, and incident triggers.
  • Structured Git Branches: Isolated feature branches per service (`feature/auth-service`, `feature/transit-service`) for clean code reviews.
